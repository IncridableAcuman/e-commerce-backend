## E-commerce API with Java Spring Boot Gradle
* **
Bu kichik loyihada men Spring Boot'ning REST APIs bilan imkoniyatlari,
shu bilan bir qatorda PostgreSQL va Redis cache bilan ishlash JWT bilan
xavfsizlikni ta'minlashni ko'rib chiqdim.
* **
### Xususiyatlar:
* **User Authentication**: Register, Login, Refresh, Logout, Forgot Password, Reset Password
* **Product Management**: CRUD
* **Cart System** Add to cart, remove cart
* **
### Texnologiyalar:

*  **Java**:OpenJDK17
*  **Spring Boot**:gradle
*  **Database**: Postgresql
*  **ORM**: Spring Data JPA
*  **Web**: Spring Web
* **Security**: Spring Security
* **Development Tools**: Lombok, Docker
* **Caching**: Redis
* **
